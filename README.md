## 📘 Descripción general del sistema
LlanquihueTourApp
Buscamos mejorar el ingreso de datos para la plataforma de Llanquihue tours, una empresa dedicada al turismo, implementamos los siguientes metodos de desarrollo orientado a obejtos:

1- Encapsulamiento de clases. 

2- Validaciones con excepciones. 

3- Clases en packages individuales para su mantenibilidad y futuro desarrollo.

## 🧱 Estructura general del proyecto


📁 src/
├── app/         # Clase principal con el método main
├── model/       # Clases de dominio (Empelado, Cliente, Proveedores, Direcciones, Rut.)
├── utils/       # Utilidades y validaciones

## ⚙️ Instrucciones para clonar y ejecutar el proyecto

1. Clona el repositorio desde GitHub:

```bash
git clone https://github.com/carcarmona-prog/SistemaInformaticoLlanquihueTours.git
```

2. Abre el proyecto en IntelliJ IDEA.


3. Ejecuta el archivo `Main.java` desde el paquete `app`.

4. Sigue las instrucciones en consola o en la interfaz gráfica (si corresponde).
